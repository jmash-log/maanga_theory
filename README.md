### Project Description

Mallu Goblin is a Chrome extension that lives on your webpage and watches what you type. When it recognizes a Manglish word like `thenga`, `chaya`, or `amma`, the Goblin reacts with an emoji and an unnecessarily dramatic message.

Because apparently translating Manglish into emojis was a problem that desperately needed solving.

### The Problem (that doesn't exist)

Malayalis type Manglish every day. But apparently, our browsers don't understand the emotional importance of words like `thenga`, `chaya`, or `exam`.

So we decided that the real problem was not the lack of Manglish translation tools.

The real problem was the **absence of a Goblin reacting to them.**

### The Solution (that nobody asked for)

We put a little Goblin inside your browser.

The Goblin watches what you type, checks completed words against its tiny Manglish dictionary, and reacts when it recognizes one.

For example:

`thenga ` → 🥥 → **THENGAAAA!**

If it doesn't know a word, it simply asks:

**"What's that word? Can you tell Ash and Anamika to teach me?"**

It doesn't actually learn yet.

It just has trust issues and homework.

# Installation

```bash
git clone https://github.com/jmash-log/maanga_theory
```

Then:

1. Open Chrome.
2. Go to `chrome://extensions`
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the Mallu Goblin project folder.

# Run

1. Open a normal webpage.
2. Click the Mallu Goblin extension.
3. Start typing Manglish words.
4. Add a space after the word to trigger the Goblin.

Try:

```text
thenga 
chaya 
amma 
exam
chechi
chettan
assignment
etc...
```
